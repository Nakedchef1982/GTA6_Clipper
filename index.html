GTA6 Clipper

GTA6 Clipper is a personal desktop tool that turns highlights from Twitch livestreams into vertical short-form videos (1080x1920) with captions and a hook text. The tool runs on the owner's own Windows computer.

What it does with TikTok

  • The owner signs in once with their own TikTok account (Login Kit) and authorizes the app.
  • The app uploads finished short videos to that same account using the Content Posting API (Direct Post).
  • It only posts content produced by the tool for the owner's own account, one video per detected highlight.

What it does not do

  • It does not read other users' data, does not follow, like, comment or message anyone, and does not post for other people.
  • It is not distributed to third parties; it is a single-user application.
